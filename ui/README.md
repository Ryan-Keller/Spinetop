# Spinetop UI

This package contains the operator dashboard, visible mission console, and legacy reference surfaces for the Spinetop repo.

## Current focus

- operator dashboard for mission-local work
- visible mirror rendering
- bounded, explicit mission actions

## Commands

- `npm run dev`
- `npm run build`
- `npm run lint`

Legacy demo pages may still exist for reference, but the primary UI entry points are the dashboard and visible console.
